What is Cloud Computing?
Cloud computing is the delivery of computing services such as servers, storage, databases, networking, and software over the internet (“the cloud”).
Instead of storing data or running programs only on a personal computer, users can access them online from remote servers.

Simple Example
Using Google Drive to save files online instead of storing them only on your phone or computer
.
Applications of Cloud Computing
1. Online Storage
Cloud is used to store files, photos, videos, and documents securely online.
Examples:
Google Drive
Dropbox
2. Education
Cloud platforms help in online classes, assignments, and sharing study materials.
Examples:
Google Classroom
Microsoft Teams
3. Entertainment
Streaming services use cloud computing to deliver movies and music.
Examples:
Netflix
Spotify
4. Social Media
Cloud stores user profiles, photos, and messages for social networking apps.
Examples:
Instagram
Facebook
5. Business Services
Companies use cloud for emails, meetings, and customer management.
Examples:
Microsoft Office 365
Salesforce
6. Backup and Recovery
Important data can be backed up and restored easily during data loss.
7. Healthcare
Hospitals use cloud to store patient records and medical reports.
8. Banking and E-Commerce
Banks and shopping websites use cloud for secure online transactions.
Examples:
Amazon
Flipkart

Advantages of Cloud Computing
Access data from anywhere
Cost-effective
Large storage capacity
Easy data backup
Fast sharing and collaboration
